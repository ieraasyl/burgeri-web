**Хакатон кейс №1: Разработка системы автоматизации процесса списания на торговых точках**

**Цель:**

Создать мобильное веб\-приложение или программу для цифровизации и контроля фактических процессов списания, которые происходят на торговых точках.

**Основной функционал системы:**  
Сотрудники торговых точек должны иметь возможность через телефон отправлять заявки на списание продукции в онлайн-формате.

**Примеры списаний:**

* лишние или не соответствующие стандартам помидоры;  
* котлеты, которые невозможно повторно использовать после приготовления;  
* поврежденные или помятые булочки;  
* упавшая котлета, которая не может быть использована по санитарным требованиям;  
* другие фактические списания, возникающие на торговой точке.


  
**Процесс работы:**

1. Сотрудник подготавливает продукцию, которая подлежит списанию.  
2. Заходит в мобильное приложение или веб\-браузер.  
3. Прикрепляет фотографию продукции (для подтверждения фактического состояния)  
4. Выбирает торговую точку из списка.  
5. Выбирает тип списания:  
* без удержания с сотрудника;  
* с удержанием с сотрудника.  
6. Если выбрано удержание — из списка выбирается сотрудник, с которого необходимо произвести удержание.  
7. Добавляется обязательный комментарий (минимум 10 символов).  
8. Заявка отправляется на проверку ответственному сотруднику.

**Функции проверяющего:**

**Проверяющий должен иметь возможность:**

* просматривать заявки;  
* проверять фото и введенную информацию;  
* подтверждать или отклонять заявку.

**Интеграция с Iiko:**  
**После подтверждения заявки:**

* система автоматически создает акт списания в Iiko;  
* данные передаются в Iiko;  
* соответствующие остатки автоматически списываются.

**Роли пользователей:**

**1\. Отправитель (сотрудник торговой точки):**

* создание заявки на списание;  
* добавление фотографии;  
* заполнение информации по списанию.

**2\. Проверяющий:**

* контроль заявок;  
* подтверждение или отклонение списаний.

**Дополнительные требования:**

* удобный интерфейс для мобильных устройств;  
* индивидуальный доступ для каждого пользователя;  
* сохранение истории всех списаний;  
* интеграция с системой Iiko.
